# 🗺️ Adventure Game

👋 Welcome! This is a small, text-based adventure game I created using Python. It’s an interactive story where your choices decide what happens next — you’ll explore paths, make decisions, and try to survive until the end!

## 🎮 What the Game Is About

You start the game as the main character on a mysterious adventure. As you play, you’ll be given choices — like whether to go left or right, across or around a lake, or visit a house or river. Each choice affects your journey and the number of hearts (lives) you have. If you lose all your hearts, the game ends. If you make smart choices, you’ll survive to the end!

## 🧠 What You’ll Need to Play

You don’t need any coding background to play this game! You’ll just need to:

- Have Python 3 installed on your computer (you can download it for free at [python.org/downloads](https://www.python.org/downloads/)).
- Have the game file saved on your computer (it should be named something like `adventure_game.py`).

## 🕹️ How to Run the Game

Here’s how to start playing:

### 🖥️ If You’re on Windows:
1. Open the Start Menu and search for **Command Prompt**.
2. Navigate to where the game file is saved. For example, if it’s in your Downloads folder, type: 
cd Downloads
3. Run the game by typing: 
python adventure_game.py
4. The game will start in your terminal window — just follow the instructions on screen!

### 🍎 If You’re on Mac:
1. Open **Terminal** (you can find it in Applications → Utilities → Terminal).
2. Navigate to the folder where you saved the file. For example:
cd Downloads
3. Run the game:
python3 adventure_game.py
4. You’ll see the story appear, and you can type your answers as you play.
