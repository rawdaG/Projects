# 🎮 Tetris Game with Python & Pygame

👋 Welcome! This is a classic Tetris game I built using **Python** and **Pygame**. It’s a graphical game where you control falling blocks, rotate them, and try to complete rows to score points.

---

## 🧩 About the Game

Tetris is a puzzle game with a **10 x 20 grid** where different shaped blocks (S, Z, I, O, J, L, T) fall from the top. Your goal is to:

- Move and rotate the falling blocks.
- Fill horizontal lines completely to clear them.
- Avoid stacking blocks to the top of the screen — if the blocks reach the top, you lose!

---

🎮 How to Play
Arrow Left / Right: Move the block left or right.
Arrow Up: Rotate the block.
Arrow Down: Move the block down faster.
Goal: Complete rows to score points and prevent the blocks from stacking to the top.
