## 🎮 Features

- **10×20 grid** — classic Tetris dimensions
- **All 7 tetrominoes** — S, Z, I, O, J, L, T
- **Collision detection** — pieces lock when they hit the bottom or another piece
- **Line clearing** — complete a row and it disappears
- **Score tracking** — points for every line cleared
- **Game over detection** — blocks reach the top and it's over

---

## 🕹️ How to Run

**Requirements:** Python 3, Pygame

```bash
git clone https://github.com/rawdaG/Projects.git
cd Projects/Tetris
pip install -r requirements.txt
python3 main.py
```

**Controls:**

| Key | Action |
|-----|--------|
| ← → | Move piece left / right |
| ↑   | Rotate piece |
| ↓   | Soft drop |
