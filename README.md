## 🎮 3D AI Agent Tic-Tac-Toe
**Python · MiniMax · Alpha-Beta Pruning**

Tic-Tac-Toe is too easy — so I made it three-dimensional and gave it a brain.

The AI uses **MiniMax with alpha-beta pruning** to search the move tree and play optimally. Difficulty scales with search depth: the deeper it looks, the harder it is to beat.

> Think you can win? Probably not at full depth.

## 🟦 Tetris
**Python · Pygame · Game Dev**

A fully playable Tetris clone — 10×20 grid, all 7 tetrominoes, collision detection, line clearing, and score tracking. Built from scratch using Pygame with a real-time game loop.

> Classic game, from-scratch implementation. Every piece, every collision, every cleared row — written by hand.
